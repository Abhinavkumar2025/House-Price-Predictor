# House Price Predictor

A machine learning project that predicts house prices using regression techniques based on various housing features. This project demonstrates an end-to-end ML pipeline including data preprocessing, feature engineering, model training, and evaluation.

---

## Overview

The goal of this project is to build a predictive model that estimates house prices using structured housing data. It covers the complete workflow from raw data handling to model optimization.

---

## Tech Stack

- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib  
- Seaborn  

---

## Features

- Data cleaning and preprocessing  
- Handling missing values  
- Log transformation to reduce skewness  
- One-hot encoding for categorical features  
- Feature engineering (room ratios, household density)  
- Exploratory Data Analysis (EDA) using visualizations  
- Model training using Linear Regression and Random Forest  
- Hyperparameter tuning using GridSearchCV  

---

## Machine Learning Concepts

- Regression Models (Linear Regression, Random Forest)  
- Data Preprocessing  
- Feature Engineering  
- Model Evaluation (R² Score, Cross-validation)  

---

## Results

- Linear Regression: Baseline performance  
- Random Forest: Improved performance  
- Achieved approximately **0.82 R² score** on test data
